# Workspace Customizations (.agents)

This directory contains workspace-specific customizations for AI agents (Google Antigravity, Gemini Code Assist, etc.):

- **`rules/`**: Modular rules automatically loaded by Antigravity and hierarchical walkers:
  - [`code-style.md`](file:///Users/user/Local/projects/ts-cheat-sheet/.agents/rules/code-style.md): Mandatory English language rule, TypeScript strict typing standards, and modern clean code conventions.
  - [`exercise-standards.md`](file:///Users/user/Local/projects/ts-cheat-sheet/.agents/rules/exercise-standards.md): Mandatory 3-phase template for all coding challenges and interactive notebooks.
  - [`architecture.md`](file:///Users/user/Local/projects/ts-cheat-sheet/.agents/rules/architecture.md): Taxonomy of levels `01_` through `09_`, naming conventions, and environment tools.
- **`skills/`**: Reusable procedure runbooks and scaffolding assistants:
  - [`new-exercise/SKILL.md`](file:///Users/user/Local/projects/ts-cheat-sheet/.agents/skills/new-exercise/SKILL.md): Scaffolds new TypeScript/JavaScript coding challenges adhering to the 3-phase template, English-only rule, and automated assertion validations.
